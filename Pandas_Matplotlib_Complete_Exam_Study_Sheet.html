07 / Editing data

Add, insert, drop — and the inplace trap

LECTURE EXAMPLES
# Assignment: add/update a column
df['Genre'] = genre

# insert(loc, column, value): insert at an exact position
df.insert(2, 'Genre', genre)

# drop: returns modified copy unless instructed otherwise
df = df.drop(columns=['Genre'])

# another approach
df.drop(columns=['Genre'], inplace=True)

The individual statements above demonstrate alternatives; do not run all of them in sequence on a DataFrame that already has a Genre column. A duplicate name can raise an error.

MethodImportant parametersReturns
df.insert(loc, column, value)loc position (0-based), column name, value data, allow_duplicates optionalChanges df itself; returns None

Never write df = df.insert(...). It changes df to None. Also, df.drop(...) alone normally does not persist the changed DataFrame.

The Titanic lecture uses median for numeric Age (less sensitive to outliers) and mode for categorical Embarked. This pattern is also required by the past-paper cleaning task. Pandas-2-Titanic.pdf p. 2

Most frequently occurring value(s).

TEACHER'S TITANIC MISSING-DATA SOLUTION
df['Age'] = df['Age'].fillna(df['Age'].median())

df['Embarked'] = df['Embarked'].fillna(
    df['Embarked'].mode()[0]

Dry run: why median instead of mean?

20222426100

Mean = (20 + 22 + 24 + 26 + 100) / 5 = 38.4, while median = 24. The extreme value 100 strongly changes the mean, but not the median.

10 / Multiple statistics

.agg() and named aggregation

When the paper asks for customer count and average bill for every Contract × AgeGroup, use multiple aggregations. The following named aggregation is especially clear. Past paper Q2

SOLUTION PATTERN • two group keys, two results
summary = df.groupby(
    ['Contract', 'AgeGroup'],
    observed=True
).agg(
    Customer_Count=('CustomerID', 'count'),
    Mean_Monthly_Bill=('MonthlyBill', 'mean')

print(summary)
Remember the template: OutputName=('ExistingColumn', 'aggregation'). The first element is the column to analyze; the second is the operation to apply.

11 / Feature engineering

pd.cut() — numeric ages → labeled categories

Definition: binning converts a continuous numeric variable into category intervals. The Titanic lecture uses explicit edges; the past paper asks for a number of equal-width bins. Distinguish the two. Pandas-2-Titanic.pdf pp. 5–7

TEACHER'S TITANIC EXAMPLE • explicit edges
ageBins = [0, 16, 25, 50, 100]
ageLabels = ['Child', 'Young Adult', 'Adult', 'Senior']

df['AgeGroup'] = pd.cut(
    df['Age'],
    bins=ageBins,
    labels=ageLabels,
    right=True
)

ageGroupSurvival = df.groupby(
    'AgeGroup', observed=True
)['Survived'].mean()

Interactive pd.cut() dry run

Teacher's Titanic bins [0, 16, 25, 50, 100] with right=True. Type an age to see its category and boundary rule.

With these explicit bins, 0 is excluded from the first interval (0,16]. Use include_lowest=True to include the lowest boundary. Values outside the range become missing categories.

Essential parameters

ParameterWhat it controlsExample
xNumeric values to groupdf['Age']
binsNumber of equal-width bins OR explicit bin edges3 or [0,16,25,50,100]
labelsBin names; one name per interval['Young','Adult','Senior']
rightWhether right boundary is includedTrue gives (a,b]
include_lowestInclude lowest boundary of first binTrue
retbinsAlso return calculated boundariesTrue
PAST PAPER • THREE EQUAL-WIDTH GROUPS
df['AgeGroup'] = pd.cut(
    df['Age'],
    bins=3,
    labels=['Young', 'Adult', 'Senior']
)
Do not confuse: bins=3 means calculate three equal-width intervals automatically, while bins=[0,18,40,100] uses those exact edges. Four edges make three intervals. right=True includes the RIGHT boundary.

Extra: pd.qcut(..., q=4) makes quantile groups (roughly equal numbers of values), unlike pd.cut(..., bins=4), which makes equal-width numeric intervals. Focus on pd.cut() for the lecture exam.
